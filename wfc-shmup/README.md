# WFC 무한 스크롤 배경 생성기

Soni Seli, *"Procedural Generation using Wave Function Collapse Algorithm"*
(POLIS University, 2025) 의 Tiled Model 을 **무한 스크롤 슈팅게임 배경**에 맞게
개조한 구현입니다.

`index.html` 하나만 브라우저로 열면 바로 돌아갑니다. 의존성 없음.

```
↑↓←→ / WASD  이동      SPACE  발사
D  디버그(타일 위치코드 + 커밋 경계)   R  시드 변경   [ ]  스크롤 속도   P  일시정지
```

---

## 논문 구현과 달라진 점

논문의 알고리즘은 **고정 크기 그리드를 한 번에 푸는 것**을 전제합니다.
무한 맵에 그대로 옮기면 세 군데가 깨집니다.

| 논문의 전제 | 무한 스크롤에서 깨지는 이유 | 이 구현의 대응 |
|---|---|---|
| 전체 그리드를 한 번에 풀이 | "전체"가 존재하지 않음. super-linear 복잡도라 크게도 못 만듦 | **밴드 단위 스캔라인 풀이** |
| 모순 시 실패하고 종료 (greedy) | 무한 스트림에서 한 번만 실패해도 게임이 멈춤 | **커밋 지연 + 재시도 + 이음매 폴백** |
| collapse 즉시 `Instantiate` | 오브젝트가 무한히 누적 | **풀이/렌더 분리 + 행 프루닝** |

### 밴드 스캔라인 풀이

세로 스크롤에서 무한한 축은 **하나뿐**입니다. 가로 폭 `W` 는 고정이므로
전체를 풀 필요 없이 가로 한 줄씩 앞으로 밀어내며 풀면 됩니다.

```
      ↑ 스크롤 방향 (무한)
 ┌────────────────────┐
 │  미확정 (제약 없음)   │
 ├────────────────────┤ ← 밴드 상단
 │    활성 밴드         │   여기만 풀이 (W × 18)
 │    18행              │   min-entropy 스캔 범위도 여기까지
 ├────────────────────┤ ← 커밋 경계: 9행만 확정
 │  확정 (동결)          │   전파가 여기서 멈춤 → 비용 상한
 │  앵커 행 ─────────── │ ← 다음 밴드의 유일한 입력
 ├────────────────────┤
 │  화면 밖 → 해제       │
 └────────────────────┘
```

논문의 super-linear 복잡도는 (1) 매 스텝 전체 N셀을 스캔해 최소 엔트로피를 찾고
(2) 전파가 최악의 경우 그리드 전체를 건드리는 데서 나옵니다. 둘 다 밴드로
제한되면 **행당 O(1) 상각**이 되어 스크롤 거리에 선형이 됩니다.

`18행을 풀고 9행만 확정`하는 lookahead 가 모순 방지의 핵심입니다.
9행 뒤까지 성공적으로 이어진 해만 확정하므로 막다른 길에 스스로 걸어
들어가지 않습니다.

### 그 밖의 변경

- **규칙 선언을 절반으로.** 논문은 4방향 리스트를 전부 수작업으로 채워
  상호성(reciprocity)이 깨지기 쉬웠습니다(논문이 직접 지적한 error-prone 지점).
  여기서는 `RIGHT`/`DOWN` 만 선언하고 `LEFT`/`UP` 은 자동 유도하므로
  규칙 비대칭 버그가 구조적으로 불가능합니다.
- **도메인을 비트마스크로.** `List<Tile> tileOptions` → `int32` 하나.
  교집합/합집합이 1클럭이고 엔트로피는 popcount 입니다. (타일 ≤ 31개)
- **경계를 명시적 제약으로.** 맵 밖을 `V`(공백)로 취급해 전파에 태웁니다.
  "폭 안에 들어갈 수 없는 구조물"을 사후 모순이 아니라 **사전에** 제거합니다.
- **페이싱 제어.** 순수 WFC 는 균질한 텍스처만 만들고 리듬이 없습니다.
  구조 타일의 가중치에 `y`의 저주파 함수를 곱해 한산한 구간과 빽빽한 구간을
  교대시킵니다.

### 좌표계 주의

논문은 Y가 아래로 증가하지만 이 구현은 **위로** 증가합니다. 따라서 솔버는
구조물을 아래에서 위로 쌓고, 빈 공간 위에 처음 놓이는 것은 타일아트 기준
**아랫줄(`D*`)** 입니다. 생성 트리거는 `RUL` 이 아니라 `RDL` 이고,
`RUL` 은 덮개라서 높이를 결정합니다.

## 타일셋

논문의 3×3 위치 시스템을 그대로 씁니다 (`D` 키로 확인 가능).

- `V` — 우주 공간. 논문의 Grass 에 해당하는 범용 커넥터 겸 경계 조건
- `R**` — 암석 덩어리 9종. `MM` 이 상하좌우로 늘어나 임의 크기가 됩니다
- `S**` — 스테이션 링 8종. 논문의 *"Mountain/Castle 의 MM 을 Grass 로"* 트릭을
  적용해 중앙이 비어 있고, 정확히 3×3 고정 크기의 랜드마크가 됩니다

밀도 손잡이는 4개뿐입니다. 나머지 타일은 전파로 강제되므로 가중치가
결과에 거의 영향을 주지 않습니다.

| 가중치 | 효과 |
|---|---|
| `RDL` | 암석 생성 빈도 |
| `RDM` vs `RDR` | 덩어리 가로 길이 |
| `RML` vs `RUL` | 덩어리 세로 길이 |
| `SDL` | 스테이션 생성 빈도 |

단, **밀도 곡선은 `V`를 제외한 구조 타일 전체에 곱합니다.** `RDL` 에만 곱하면
제어가 새어나갑니다 — `RDM` 을 고르는 것만으로도 전파가 왼쪽에 `RDL` 을
채워넣어 덩어리가 생기기 때문입니다.

## 측정 결과

브라우저(Chromium)에서 실측한 값입니다.

**안정성 — 시드 20개 × 5,000행 = 총 100,000행**

```
밴드 11,120 / 재시도 0 / 이음매 폴백 0 / 규칙 위반 0
```

규칙 위반은 생성된 전 구간을 인접 규칙과 독립적으로 재검증한 값입니다.

**스케일링 (W=20)** — 논문은 50→100에서 10배 이상 증가(super-linear)했지만,
밴드 풀이는 선형입니다.

| 행 수 | 시간 | 배율 |
|---|---|---|
| 250 | 44ms | – |
| 500 | 93ms | ×2.09 |
| 1,000 | 180ms | ×1.93 |
| 2,000 | 342ms | ×1.90 |
| 4,000 | 716ms | ×2.10 |

**밀도 제어 (3,000행)**

| density | 점유율 | 이음매 |
|---|---|---|
| 0 | 0.0% | 0 |
| 0.5 | 16.1% | 0 |
| 3 | 34.8% | 0 |
| 10 | 44.8% | 0 |
| 500 | 53.0% | 0 |

53% 가 이 타일셋의 기하학적 상한입니다. 덩어리끼리는 반드시 `V` 한 칸을
사이에 둬야 하기 때문(`RUR.right = V`)입니다. 더 빽빽하게 채우려면
덩어리끼리 맞닿을 수 있는 전이 타일을 추가해야 합니다.

**메모리** — 무한히 생성해도 보유 행 수는 90~100행에서 일정합니다.

## 알려진 한계

- **덩어리가 전부 축정렬 직사각형입니다.** 3×3 시스템에 `MM` 신축을 더하면
  나올 수 있는 모양이 직사각형뿐입니다(논문의 호수도 같은 성질). 실루엣을
  깨려면 모서리를 깎는 전이 타일이나 두 번째 구조물 세트가 필요합니다.
- **모순 0은 이 타일셋에 대한 실측이지 증명이 아닙니다.** 규칙을 바꾸면
  다시 측정해야 합니다. HUD 의 `retry` / `seam` 카운터가 그 지표입니다.
  모든 타일이 4방향 모두에서 `V` 를 허용하도록 만들면 모순이 원리적으로
  불가능해지지만(항상 `V` 로 채워 완성 가능), 실루엣이 지저분해집니다.
- **랜덤 액세스가 안 됩니다.** 밴드 N은 밴드 N-1의 마지막 행에만 의존하므로
  시드에서 결정론적이지만, 임의 위치로 점프하려면 처음부터 재생해야 합니다.
  세로 스크롤 슈팅은 항상 앞으로만 가므로 실무상 문제가 되지 않습니다.
- 적 기체와 충돌은 없습니다. 배경 생성에 집중한 데모입니다.

## 충돌 레이어로 확장하려면

현재는 장식 전용입니다. 부딪히면 죽는 지형으로 쓰려면 세 가지가 더 필요합니다.

1. **통과 가능성 보장.** WFC 는 지역 일관성만 보장할 뿐 "길이 막히지 않음"은
   보장하지 않습니다. 밴드를 커밋하기 **전에** 각 행의 빈 칸 폭을 검사해
   최소 통로 폭(기체 폭 + 여유)을 만족하지 않으면 그 밴드를 재시도하세요.
   밴드가 작아서 재시도가 저렴한 것이 여기서도 이점이 됩니다.
2. **사전 붕괴(pre-collapse) 주입.** 밴드를 풀기 전에 특정 셀을 강제로
   확정해두면 WFC 가 그 주위를 알아서 채웁니다. 보스 구간의 개활지,
   정해진 랜드마크, 안전 통로를 이런 식으로 심습니다.
3. **충돌 조회.** `wfc.tileAt(x, y)` 가 이미 있으니 타일별 `solid` 플래그만
   추가하면 됩니다. 스프라이트 단위가 아니라 타일 단위 AABB 로 검사하세요.

장식 레이어와 충돌 레이어를 **별도 `InfiniteWFC` 인스턴스**로 두는 편이
좋습니다. 충돌 레이어는 통로 보장 때문에 제약이 훨씬 빡빡해서, 한 타일셋에
두 목적을 섞으면 양쪽 다 나빠집니다.
